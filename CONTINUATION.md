## 1. What the project is

A public GitHub-ready **agent skill pack** at `D:/reel-editor/animation-skill/`:
when another AI coding agent reads it, that agent can turn a one-line idea
("a stickman gets surprised and jumps") into a finished 2D code-drawn
animation (stickman/explainer style) without further instruction. The weak
agent's known failure points — character drift, unbelieving motion,
composition, asset reuse, self-verification, rendering/export — must each
be removed by concrete instructions, reusable tested code, and checklists.

**Tech:** default = HTML + CSS + SVG + vanilla JS (zero-install, seekable).
Optional upgrades: GSAP template, Three.js orthographic 2D, Remotion.
Export: headless-Chromium per-frame capture → PNGs → ffmpeg → MP4/GIF.
User constraint: **default path must stay free and install-light**
(Playwright's ~118MB Chromium download is the only heavy bit; that's
acceptable, document it). Paid services (ElevenLabs TTS) must be optional
with a free fallback / skip-audio mode.

## 4. Architectural decisions already made (don't relitigate)

- **The rig is the character.** One `rig.js` for everything; the
  "drawn differently per shot" drift failure mode is killed by
  construction. `library/svg/` (if built) must be *generated from the
  rig or at least mirror its proportions* (DEFAULTS: headR 16,
  torso 55, arm 28+28, leg 35+35, height 142, strokeWidth 4,
  color #1c1c1c), never a separate hand-drawn system.
- **Y-up local space, hip at origin**, `facing: ±1` mirrors the pose
  (`solve(pose, {facing:-1})` must give mirrored results — tested).
- **Seek contract:** `window.__seek(frame)` + `window.__ready()` on
  every template. No SMIL, no wall clock. CSS-only scenes would use
  `document.getAnimations().forEach(a=>{a.pause(); a.currentTime=t})`
  (the stix pattern, documented in references/12 trap e) but our JS
  templates use `__seek`.
- **Pose model = joint angle records** (not SVG coordinate pastes),
  so `blendPose` interpolates. `walkPose(phase, gait)` is the
  locomotion primitive; gait numbers: walk cyc 1.5/s stride 44
  stepH 15 duty 0.62 bob 5; run cyc 2.55/s stride 60 stepH 26
  duty 0.40 bob 12; `scroll = stride × cyc ÷ duty` (walk ≈106, run
  ≈383 u/s).
- **8s default scene duration** (stix convention, kept as default,
  not law); fps 30 default for MP4, 12 for GIF.
- Sources: MIT/CC0 repos copied/paraphrased are what-if-animation,
  stix, LottieFiles motion-design-skill, iart-ai skills,
  ShengyuStudio article (technique). GPL (StykAnimate-App) = ideas
  only, never code. All this is in references/00; ATTRIBUTION.md
  still to be written — it should mirror the 00 table plus name the
  exact snippets (e.g. two-bone IK from ShengyuStudio's snippet;
  gait table numbers; ffmpeg flags from stix capture.sh).
